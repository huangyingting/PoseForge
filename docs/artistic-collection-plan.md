# Ready-to-view artistic posture collection

## User-approved scope

Deliver 1,283 original, clothed, non-graphic 3D posture compositions as built-in
content. Each source ID gets a distinct artistic interpretation automatically;
the user does not author, import or install anything. These are not faithful
reconstructions of source interactions. Figures remain separate on a floor.
Existing personal studies take precedence and must not be overwritten.

## Content design

Compose whole-body studies from a deliberately designed gesture vocabulary:
rest, open arms, forward/diagonal/overhead reaches, bent-elbow frames and
asymmetric reaches, with neutral gaze variations. Use grounded standing,
kneeling, floor-seated and reclining bases. Broad source families guide the
palette, not original contact relationships. Supported/ambiguous families use
grounded artistic alternatives, not invented furniture or suspended bodies.

Bake complete fixed joint angles and placements into a committed pack. Retain
all 2,567 participants. Reject duplicate composition motifs and duplicate joint
signatures even when titles, actor order, model choice, colours, placements or
cameras or gaze differ. Quantize body-joint angles for the signature so numerical noise is not
counted as new content. Report distinct joint configurations and composition
counts separately from source IDs; do not claim 1,283 hand-sculpted base poses.

## Integration

- A fresh visit opens **Artistic 3D** for each reference by default; local
  authored studies still override it. Retain the earlier approximate pack behind
  **Open generated approximation** and its existing URL option.
- Load the artistic pack lazily with bounded byte/hash/schema validation.
  Source links, editing, saving, export, retry and cancellation still apply.
- Keep source identity/hash separate from artistic intent. Prominent labels,
  captions and export metadata must say artistic, non-verified interpretation.
- Ship a deterministic offline builder and the actual ready-to-view data.
  Do not populate or rewrite the user's personal library.

## Verification and delivery

Reconcile every source ID and participant; validate portable scenes, clothing,
complete fixed poses, joint limits, separated bounds and meaningful uniqueness.
Render every composition with the existing scanned/clothed mesh pipeline and
renderer in a bounded audit harness, checking finite vertices/normals and visible
pixels. Exercise representative compositions through the full application worker
plus catalog/default selection, fallback, local overrides, failure/race, export
and mobile flows. Distinguish direct-render coverage from full-worker coverage.
Report remaining coarse support/collision limitations rather than certifying
anatomy or physics. Run relevant unit, browser, build and dependency gates;
archive sanitized evidence and deliver the authorized iteration to private main.
No hosted deployment or new dependency.
